聊天记录整理器 把一堆聊天记录，整理成时间线 / 承诺提取 / 待办清单 / 证据目录

🔒 纯本地运行 · 数据不上传
隐私说明：本工具是一个网页文件，所有处理都在你的浏览器里完成，不会把任何内容发送到服务器。你可以断开网络后使用。 你可以整理自己的聊天记录；用于他人数据时，请确认你已获得合法授权。

第一步 · 导入聊天记录

支持直接粘贴文本，或上传 .txt / .html 导出文件。兼容微信、Telegram、QQ 等常见导出的纯文本格式。

识别不了的格式？点击这里看支持哪些输入样式 
工具会尽量解析下面几种常见写法，认不出来时会按「整行一条」处理：

1) 发言人 + 时间 在两行（微信 PC 导出常见）
   张三 2026-03-01 14:22:15
   消息内容……

2) 时间 + 发言人 在一行
   [2026-03-01 14:22:15] 张三：消息内容

3) 发言人：消息（无时间）
   张三：消息内容

4) 只有发言人（按出现顺序编号）
   张三
   消息内容

5) 纯段落（每行算一条，发言人显示为「未知」）

上传 .html 文件时会自动剔除标签，只保留文字。

按时间排序的完整记录

已按时间戳升序排列；无时间戳的条目保留在原始顺序末尾。

含承诺 / 风险关键词的句子

命中「同意、答应、一定、保证、转账、周五之前、尾款、违约、否则」等词，已高亮。供你快速定位关键承诺。

待办与约定

从记录中抽取含「下周 / 之前 / 截止 / 需要 / 麻烦 / 请」等时间或动作指向的句子。

证据目录（可直接打印）

按日期归档的条目清单，适合作为材料附件或移交清单。点击「打印 / 存 PDF」可用浏览器直接生成 PDF。

发言人发言统计

按发言条数排序。可用于快速判断对话结构与主导方。

复制下面这段提示词，连同你整理好的记录一起发给任意 AI 助手，可以让它进一步提炼争议焦点、责任归属和证据缺口。
